Data interpretation

Pressure input is assumed to be Pa, as documented for these project files. Coordinate units remain file units. Selecting seconds changes the time label only.

Original samples are used in plots and CSV. Frame contours interpolate linearly between stored samples, with no extrapolation. Missing values are never replaced by zero.

PressHist Assign, load multipliers and solver mapping are not evaluated. This viewer displays explicit element histories. Nodes show original coordinates; no nodal pressure is inferred.

Inspect. Select. Compare.

Open or drop pCloud/USFOS .fem files. Switch the active dataset to change the visible mesh. Selected curves from other files stay in the plot.

  • 3D: drag to rotate; right-drag to pan; wheel to zoom. Click a panel to add/remove it. Use Fit or F to restore the camera.
  • Display: Appearance & IDs controls node/element labels, surface, mesh edges, background and spectrum. Labels avoid overlaps; zoom in for more IDs. PNG export includes the displayed labels and chosen colours.
  • Nodes and rotation: Switch Select objects to Nodes to click a node or enter its ID and inspect original X, Y, Z. No nodal pressure is inferred. Rotation uses the bounding-box centre of selected geometry in the active model; clearing selections restores the model centre. Selecting objects recentres the view without changing zoom.
  • History: enter an element ID or click the mesh. Each selected card reports its extrema and times. Click a card's title to activate its source dataset and case.
  • Time: drag the slider, type a time (nearest stored frame), or use left/right arrows. Space starts or pauses playback, measured in stored frames per second.
  • Plots: wheel to zoom the time axis, drag to pan, double-click to reset. Hover to inspect nearest original samples. Curves share the file time origin; no time shift or element matching is inferred.
  • Envelopes: min/max use the chosen sign. Absolute peak shows magnitude. These fields combine different occurrence times and are not one physical frame.
  • Export: CSV contains native samples in long form, including source, case, ID, units and sign. Missing selections are marked explicitly. PNG buttons save the view or plot.

Only NODE / QUADSHEL / PressHist Define LoadElem exports are supported. Geometry is static; this is a pressure-data viewer, not a structural solver.
